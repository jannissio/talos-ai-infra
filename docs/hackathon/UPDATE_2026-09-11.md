## Requirements retained in our plan

| Published requirement | Current physical milestone | Still required for the submission |
|---|---|---|
| MuJoCo and two SO-101 arms | Both arms simulated; left handles bottle/plate/drawer/cutlery, right handles mug | Genuine coordinated or complementary two-arm action |
| Open a drawer, retrieve spoons/forks, arrange plate/cup | Contact-only controllers and a six-skill sequence | Broader robustness and camera-driven execution |
| Natural language and camera scene context | Exact-state teacher explicitly identified in the UI | Language/vision interpretation and observation-based control |
| Train/fine-tune a robotics policy, e.g. ACT, SmolVLA, Pi0.5 or equivalent | A physical teacher suitable for future demonstration collection | Dataset, training/fine-tuning, held-out policy evaluation |
| Variation in weight, friction, shape, lighting/background and placement | Seeded placement/yaw, mass, friction and mild lighting variation | Shape/background coverage and learned-policy robustness |
| Run on Core Ultra Series 2/3; OpenVINO where supported | Local PC development only | Actual qualifying Intel hardware, export and measured benchmark |
| Reproducible code, training/evaluation/inference, technical README and ten randomized demonstration runs | Source, original assets, physical evaluation scripts and telemetry | Complete submission package and ten-seed video evidence |
| Speechmatics bonus | Planned spoken interface | Real Speechmatics integration and demonstrated use |

The rubric remains: task/bimanual execution 30%, reasoning 20%, robustness 15%, Intel optimization 20%, reproducibility 10%, innovation 5%. A successful exact-state sequence does **not** satisfy the learned-policy, reasoning, bimanual coordination or Intel requirements by itself.

Our scene is an original, compact development scene. The checked brief describes the task but does not fix this particular table layout, item dimensions or target coordinates. The changed drawer dimensions, thick utensil handles and shallow rimmed plate are documented engineering choices, not organizer specifications.
