03 / THE CONTROL PATH

Each component has a clear job.

  1. 01

    Understand

    Speechmatics transcribes speech. A bounded interpreter selects supported tasks.

  2. 02

    Observe & move

    Camera features condition neural motion. Joint feedback regulates progress.

  3. 03

    Verify

    A separate physical monitor checks contact, release and placement. It does not generate learned actions.
