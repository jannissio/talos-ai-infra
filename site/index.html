03 / THE CONTROL PATH

Each component has a clear job.

  1. 01

    Understand

    Speechmatics transcribes speech. A bounded grammar and RGB scene checks select supported tasks and preparation steps.

  2. 02

    Observe & move

    Each skill's initial camera features condition neural joint targets. Motor feedback regulates progress and transitions.

  3. 03

    Verify

    A separate simulator-state monitor checks contact, release, placement and parked arms. It does not generate learned actions.
